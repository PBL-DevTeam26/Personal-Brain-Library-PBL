# PBL – M1.6: API, GitHub and implementation baseline

**Status:** M1 architecture definition completed; implementation bootstrap created locally. No deployment, PR, real auth, or AI/ML model completion claimed.

## Agreed decisions

- Existing organization/repo: `PBL-DevTeam26/Personal-Brain-Library-PBL-`.
- One monorepo, feature branches and pull requests.
- **Code-first** API: Express route JSDoc produces OpenAPI through swagger-jsdoc. Zod validates payloads at runtime. Contract drift must be checked in PR reviews.
- First build priority: backend + datamodel + functional quiz API.
- Local Docker development; Oracle Cloud VM later as isolated test environment.
- Own Node.js authentication developed independently, not publicly bypassed during development.
- Both Android and web mandatory MVP platforms.
- Budget target: 0 DKK incremental, not a cost guarantee.

### Internal service contracts (planned)

- `POST /internal/ml/rank`: candidate features and interest scores.
- `POST /internal/ml/train`: async job request; authorized service only.
- `GET /internal/ml/models`: models and evaluation metadata.
- `POST /internal/events/answer-created`: trusted worker-to-workflow event.
- `POST /internal/taxonomy/proposals`: validated candidate proposal.
- Internal routes must be network restricted and authenticated before deployment.

## Data ownership

PostgreSQL owns users, sessions, questions, answers, preferences, impressions and outbox. Neo4j is a rebuildable derived projection, not authoritative user data storage. Embedding and inference model versions must be retained. FAISS excluded from MVP. See M1.4.

## Definition of Done

An issue is complete only when: requirements and acceptance criteria are met; code has automated tests; `typecheck` and CI pass; API schema is updated; schema changes include migrations; no secrets or personal data are committed; security boundaries and data isolation are tested; docs/ADR are updated when the decision changes; feature branch PR is reviewed by the other student; and issue links the implementing PR.

**Project-M1 gate:** architectural choices documented; endpoints and ownership defined; backlog prioritized; environment bootstrap produced. Official course rubrics, deadline, complete auth strategy, privacy retention and Oracle resource measurements remain open.
